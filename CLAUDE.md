# Content Guidelines

- All content of this website is in Vietnamese
- Always use "Đức Chúa Giê-su" instead of "Chúa Giê-su", "Jesus", or "Giê-xu"
- "ban phước" vs "chúc phước": Chúa/God "ban phước" (has authority to bless). Người/human "chúc phước" (can only wish blessings). Never use "chúc phước" when the subject is God.
- Use "Sa-bát" instead of "Sabát"
- Use "Do Thái Giáo" instead of "Giu-đa-izt"
- Use "Cơ-đốc" instead of "Cơ Đốc"
- Use "Ha-ma-ghê-đôn" instead of "Hạt-ma-ghê-đôn"
- Divine names must be capitalized correctly: "Đức Chúa Trời" (not "Đức chúa trời"), "Đức Thánh Linh" (not "Đức thánh linh"), "Kinh Thánh" (not "Kinh thánh"), "Đức Chúa Giê-su" (not "Đức chúa Giê-su"), "Hội Thánh" (not "hội thánh")
- Use "Chủ Nhật" instead of "Chủ Nhật"

# Content

Each content type has its own format spec under `docs/content/`. Read the relevant doc before creating or editing files in that section.

- [Articles](docs/content/articles.md) — `content/articles/`: single articles, sermons, devotionals
- [Tủ Sách](docs/content/sach.md) — `content/sach/`: book library (per author, per book, per chapter)
- [Kinh Thánh](docs/content/kt.md) — `content/kt/`: Bible book pages
- [Nghiên Cứu](docs/content/nghien-cuu.md) — `content/nghien-cuu/`: in-depth multi-part studies
- [Authors](docs/content/authors.md) — `content/authors/`: author profiles (front-matter only)
- [Tín Lý](docs/content/doctrines.md) — `content/doctrines/`, served at `/tin-ly/`
- [Trường Sa-bát](docs/content/truong-sabat.md) — `content/truong-sabat/`: Sabbath School lessons (use the `sabat-school` and `fetch-sabat-school-lesson` skills)
- [Loạt Bài](docs/content/series.md) — `content/series/`: thin series index entries
- [Posts](docs/content/posts.md) — `content/posts/`: reserved blog section

[Cross-cutting rules](docs/content/cross-cutting-rules.md) apply to every type (URL conventions, author references, language and terminology).
